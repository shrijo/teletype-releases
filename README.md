# Teletype for Mac

Downloads of [Teletype](https://teletype.digital), local-first notes in a 3D library.

**[Download the latest version](https://github.com/shrijo/teletype-releases/releases/latest/download/Teletype.dmg)** (Apple Silicon and Intel)

Open the disk image and drag Teletype into Applications. Builds aren't signed with an Apple
Developer ID yet: the first time, open Teletype, choose Done, then go to System Settings →
Privacy & Security and choose **Open Anyway**.
